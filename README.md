# Quiz Game

## 1. 프로젝트 개요

Quiz Game은 Python으로 제작한 콘솔 기반 퀴즈 게임입니다.
사용자는 저장된 퀴즈를 풀고 점수를 확인할 수 있으며, 새로운 퀴즈를 직접 추가할 수 있습니다.
퀴즈 데이터와 최고 점수는 JSON 파일(state.json)에 저장되어 프로그램을 종료해도 유지됩니다.

---

## 2. 퀴즈 주제와 선정 이유

주제는 일반 상식 퀴즈입니다.

일반 상식은 누구나 쉽게 접근할 수 있으며,
다양한 문제를 자유롭게 추가할 수 있어 프로그램 기능을 테스트하기에 적합하다고 판단하여 선정하였습니다.

---

## 3. 실행 방법

1. 프로젝트 폴더로 이동합니다.

2. 아래 명령어를 실행합니다.

```bash
python main.py
```

3. 메뉴에서 원하는 기능을 선택합니다.

```
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
```

---

## 4. 기능 목록

### 1) 퀴즈 풀기

- 저장된 퀴즈를 순서대로 풉니다.
- 정답 개수와 최종 점수를 출력합니다.
- 최고 점수를 갱신하면 state.json에 저장합니다.

### 2) 퀴즈 추가

- 새로운 문제를 추가합니다.
- 선택지 4개와 정답 번호를 입력합니다.
- 추가한 문제는 state.json에 저장됩니다.

### 3) 퀴즈 목록

- 현재 저장된 모든 퀴즈의 문제를 출력합니다.

### 4) 점수 확인

- 저장된 최고 점수를 확인할 수 있습니다.

### 5) 데이터 저장 및 불러오기

- 프로그램 시작 시 state.json을 불러옵니다.
- 프로그램 종료 또는 데이터 변경 시 자동 저장됩니다.
- 파일이 없으면 기본 퀴즈를 생성합니다.
- 파일이 손상되면 기본 퀴즈로 복구합니다.

### 6) 예외 처리

- 잘못된 숫자 입력 처리
- Ctrl + C(KeyboardInterrupt) 처리
- EOFError 처리
- JSON 파일 읽기/쓰기 오류 처리

## 6. 데이터 파일 설명

### 파일명

```
state.json
```

### 역할

- 퀴즈 목록 저장
- 최고 점수 저장

### 위치

프로젝트 루트

### 데이터 구조(Schema)

```json
{
    "quizzes": [
        {
            "question": "대한민국의 수도는 어디일까요?",
            "answer": 2,
            "choices": [
                "부산",
                "서울",
                "대전",
                "광주"
            ]
        }
    ],
    "best_score": 100.0
}
```

### 필드 설명

| 키 | 설명 |
|----|------|
| quizzes | 저장된 퀴즈 목록 |
| question | 문제 |
| answer | 정답 번호 |
| choices | 선택지 목록 |
| best_score | 최고 점수 |
